# 10 — Agentic Systems

Agentic systems covers tool use, orchestration frameworks, stateful workflows, and memory patterns for production AI agents.

## Learning Path

1. [MCP Servers and Clients](01-mcp-servers-clients/README.md) — tool contracts, resource exposure, client/server boundaries, and safe tool invocation.
2. [LangChain](02-langchain/README.md) — chains, tools, retrievers, prompt composition, observability, and framework tradeoffs.
3. [LangGraph](03-langgraph/README.md) — state graphs, nodes, edges, checkpoints, control flow, and human-in-the-loop recovery.
4. [Memory for AI Agents](04-agent-memory/README.md) — short-term state, long-term memory, retrieval, summarization, write policies, and forgetting.

## Section Build Target

Build a small tool-using agent loop with explicit state, safety checks, and memory.

## Completion Criteria

- Topic notes explain the core concepts and production tradeoffs.
- Exercises have matching solution outlines.
- Interview prep covers senior-level design and debugging questions.
- Mini-projects are self-contained and do not depend on hidden assets.
- Implementation notebooks and tests are deferred to the next pass.
