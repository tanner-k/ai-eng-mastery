# 12 — Cloud and Infrastructure

Cloud and infrastructure covers the runtime substrate for AI systems: packaging, orchestration, accelerators, serverless patterns, autoscaling, and cost.

## Learning Path

1. [Terraform and IaC](01-terraform-iac/README.md) — declarative infrastructure, state, modules, environments, drift, and review workflows.
2. [Docker](02-docker/README.md) — container images, layers, reproducible runtime environments, security, and build artifacts.
3. [Kubernetes](03-kubernetes/README.md) — pods, deployments, services, config, scheduling, rollout, and health management.
4. [GPU Provisioning](04-gpu-provisioning/README.md) — accelerator selection, scheduling, memory capacity, utilization, quota, and workload placement.
5. [Serverless Inference](05-serverless-inference/README.md) — scale-to-zero, cold starts, concurrency, timeout limits, and stateless inference contracts.
6. [Autoscaling and Cost](06-autoscaling-cost/README.md) — traffic forecasting, horizontal scaling, queueing, utilization, SLOs, and cost controls.

## Section Build Target

Build an infrastructure plan for serving a small AI workload under latency, reliability, and cost constraints.

## Completion Criteria

- Topic notes explain the core concepts and production tradeoffs.
- Exercises have matching solution outlines.
- Interview prep covers senior-level design and debugging questions.
- Mini-projects are self-contained and do not depend on hidden assets.
- Implementation notebooks and tests are deferred to the next pass.
