# 09 — Graphs

Graphs covers relational structure, graph storage, traversal, and graph-shaped memory for retrieval and agent systems.

## Learning Path

1. [Graph Algorithms](01-graph-algorithms/README.md) — traversal, shortest paths, centrality, connected components, and graph complexity.
2. [Graph Databases](02-graph-databases/README.md) — nodes, relationships, property graphs, queries, indexing, and transactional graph storage.
3. [GraphRAG and Agent Memory](03-graphrag-agent-memory/README.md) — entity extraction, relation updates, graph retrieval, memory consolidation, and provenance.

## Section Build Target

Build a graph-backed knowledge and memory prototype over synthetic entities.
