## Exercise 1 — Compute common norms

Let x = `[3, -4, 12]`.

Compute:

1. `||x||_1`
2. `||x||_2`
3. `||x||_inf`
4. The unit vector `x / ||x||_2`

## Exercise 2 — Compare dot product and cosine similarity

Let:

```
q = [1, 2]
a = [2, 4]
b = [4, 1]
c = [-1, -2]
```

Compute the dot product and cosine similarity between q and each candidate a, b, and c. Which candidate is most similar by dot product? Which is most similar by cosine similarity?

## Exercise 3 — Derive gradients of norm-based objectives

For x in R^d and x != 0:

1. Derive the gradient of `||x||_2`.
2. Derive the gradient of `(1/2)||x||_2^2`.
3. Explain why the second objective is often easier to optimize.

## Exercise 4 — Diagnose gradient clipping

A training job reports gradient norms for five consecutive steps:

```
0.8, 1.1, 3.7, 58.0, 420.0
```

1. What failure mode might this indicate?
2. If global norm clipping threshold is 5.0, what happens to a gradient vector with norm 58.0?
3. Why is global norm clipping usually preferred over clipping each element independently?

## Exercise 5 — Choose a retrieval metric

You own an embedding search system. Query and document vectors are generated by the same model, but document vector norms vary strongly with document length. Long documents dominate top results under raw dot product, even when they are only weakly related to the query.

1. Why can raw dot product cause this behavior?
2. Which metric would you try first?
3. What product-quality tradeoff should you check before switching metrics?
