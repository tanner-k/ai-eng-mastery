# Linear Regression — Exercises

Worked solutions are in `solutions/solutions.md`.

## Exercise 1 — Derive the normal equations

Starting from `L(beta) = ||X beta - y||_2^2`, derive the normal equations for ordinary least squares.

## Exercise 2 — Compute a one-feature fit

For points `(x, y) = (0, 1), (1, 3), (2, 5)`, find the best-fit line `yhat = wx + b`.

## Exercise 3 — Identify collinearity

Suppose two features are nearly identical. What happens to OLS coefficient stability, and how does ridge regularization help?

## Exercise 4 — Interpret residual diagnostics

A residual plot shows residual magnitude increasing as predicted value increases. What assumption is likely violated, and what changes might help?

## Exercise 5 — Compare OLS and gradient descent

When would you prefer a closed-form or linear-solve solution over gradient descent, and when would gradient descent be preferable?
