# 08 — Retrieval and RAG

Retrieval and RAG covers the indexing, ranking, context construction, and evaluation layer that makes knowledge-grounded AI systems useful.

## Learning Path

1. [RAG Architecture](01-rag-architecture/README.md) — query analysis, retrieval, reranking, context assembly, generation, and citations.
2. [BM25](02-bm25/README.md) — term frequency, inverse document frequency, length normalization, and sparse retrieval.
3. [Semantic Retrieval](03-semantic-retrieval/README.md) — dense embeddings, similarity search, recall, indexing, and embedding drift.
4. [Hybrid Fusion](04-hybrid-fusion/README.md) — sparse/dense score fusion, normalization, reciprocal rank fusion, and recall tradeoffs.
5. [Reranking](05-reranking/README.md) — cross-encoders, late interaction, pairwise ranking, latency, and top-k tradeoffs.
6. [Vector Databases](06-vector-databases/README.md) — ANN indexes, metadata filters, persistence, recall/latency, and operational constraints.
7. [Chunking Strategies](07-chunking-strategies/README.md) — chunk size, overlap, semantic boundaries, metadata, and context-window economics.
8. [RAG Evaluation](08-rag-evaluation/README.md) — retrieval recall, groundedness, faithfulness, answer quality, and regression testing.

## Section Build Target

Build a small local retrieval pipeline over synthetic documents and evaluate answer grounding.
