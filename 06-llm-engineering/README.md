# 06 — LLM Engineering

LLM engineering connects transformer mechanics to the practical work of tokenization, adaptation, alignment, inference, and evaluation.

## Learning Path

1. [Transformers and Attention](01-transformers-attention/README.md) — attention scores, masking, positional information, and transformer block structure.
2. [Tokenization and Embeddings](02-tokenization-embeddings/README.md) — token boundaries, vocabulary design, embedding lookup, and similarity geometry.
3. [Fine-Tuning (LoRA/PEFT)](03-fine-tuning-lora-peft/README.md) — parameter-efficient adaptation, LoRA rank, freezing, adapters, and data quality.
4. [RLHF and DPO](04-rlhf-dpo/README.md) — preference data, reward modeling, policy optimization, and direct preference objectives.
5. [Quantization and Inference Optimization](05-quantization-inference/README.md) — precision, memory bandwidth, latency, KV cache, batching, and serving tradeoffs.
6. [LLM Evals](06-llm-evals/README.md) — task metrics, judge design, regression suites, calibration, and release gates.

## Section Build Target

Build a small language-model engineering lab with synthetic prompts and model-free simulations.

## Completion Criteria

- Topic notes explain the core concepts and production tradeoffs.
- Exercises have matching solution outlines.
- Interview prep covers senior-level design and debugging questions.
- Mini-projects are self-contained and do not depend on hidden assets.
- Implementation notebooks and tests are deferred to the next pass.
