# 07 — Reinforcement Learning

Reinforcement learning covers sequential decision-making, value estimation, bootstrapping, exploration, and policy optimization.

## Learning Path

1. [Markov Decision Processes](01-mdps/README.md) — states, actions, transitions, rewards, policies, returns, and discounting.
2. [Value Functions](02-value-functions/README.md) — state value, action value, Bellman expectation equations, and dynamic programming.
3. [Q-Learning](03-q-learning/README.md) — temporal-difference targets, bootstrapping, off-policy control, and exploration.
4. [Policy Gradients](04-policy-gradients/README.md) — stochastic policies, score-function gradients, baselines, variance, and advantage estimates.

## Section Build Target

Build a tabular environment and compare value-based and policy-based learning behavior.
